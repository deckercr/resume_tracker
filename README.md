# Job Tracker

A Flask web application for tracking job applications with full CRUD support and Excel export.

## Setup

1. **Clone or navigate to the project directory:**
   ```bash
   cd /home/deckercr/Documents/job-tracker
   ```

2. **Create a virtual environment:**
   ```bash
   python3 -m venv .venv
   ```

3. **Activate the virtual environment:**
   ```bash
   source .venv/bin/activate
   ```

4. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

5. **Run the application:**
   ```bash
   python app.py
   ```

6. **Open in your browser:**
   ```
   http://127.0.0.1:5000
   ```

The SQLite database (`job_tracker.db`) is created automatically on first run.
